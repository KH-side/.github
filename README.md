### 한지붕

**같이 사는 우리, 살림도 함께 가볍게.**

집안일을 나누고, 냉장고 속 재료와 유통기한을 챙기고,<br />
즐겨 먹는 레시피에 필요한 재료와 부족한 재료도 확인해요.<br />
청소 현황부터 청소도구와 생필품까지, 우리 집 살림을 한곳에서.

친구와 살아도, 연인과 살아도.<br />
우리 사이에 맞는 분위기로 함께 쓰는 공동생활 앱을 준비하고 있어요.
